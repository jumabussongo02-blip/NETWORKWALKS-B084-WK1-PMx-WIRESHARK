Wireshark SOC Analysis Project – Week 1

Overview

This project is part of the Networkwalks Cybersecurity Internship Program.

The objective is to develop practical SOC analyst skills through network traffic analysis using Wireshark.

The project consists of six security labs covering attacker identification, TCP stream analysis, HTTP credentials, brute force detection, and VoIP scam investigation.

Objectives

- Identify suspicious IP addresses in network traffic.
- Analyze TCP communication using Follow TCP Stream.
- Identify hidden data in network traffic.
- Understand the risks of transmitting credentials over HTTP.
- Detect repeated login attempts associated with brute force attacks.
- Investigate VoIP traffic and identify scam activity.

Tools Used

- Wireshark
- Networkwalks SOC Practice Labs
- Web Browser
- GitHub
